# LearningEN API v1

Base `/api/v1`. JSON camelCase, UUID identifiers, ISO-8601 timestamps in UTC. Cookie session (`HttpOnly`, SameSite=Lax), CSRF cookie `XSRF-TOKEN` mirrored in `X-XSRF-TOKEN` for mutations. Fetch `/auth/csrf` before login. Errors use RFC 9457 ProblemDetail (`status`, `detail`). No public registration. Lists return arrays; no invented client counts. Empty lists mean no data.

- GET `/auth/csrf` → `{token,headerName}`; POST `/auth/login` `{email,password}` → profile; GET `/auth/me` → profile; POST `/auth/logout` → 204.
- PATCH `/profile` `{displayName,dailyMinutes,timeZone,retainHistory}` → profile `{id,email,displayName,dailyMinutes,timeZone,retainHistory}`.
- GET `/learning-items?q=` → `Item[]`; GET `/learning-items/{id}` → Item; POST `/learning-items` → 201 Item; PUT `/learning-items/{id}` → Item; DELETE → 204. Input `{expression,meaning,context,example,notes,tags,reviewEnabled}`; Item adds `{id,createdAt}`. Exact expression+meaning duplicates return 409 (different meanings allowed).
- GET `/review-cards?due=true` → `{id,learningItemId,expression,meaning,context,example,dueAt,version}[]`. POST `/review-cards/{id}/reviews` `{requestId,rating:AGAIN|HARD|GOOD|EASY,version}` → updated card. Replay identical requestId returns same response; stale versions or mismatched reuse return 409.
- POST `/assistant-requests` `{content,mode:AUTO|TRANSLATE|EXPLAIN|CORRECT,context,requestId,conversationId?}` → `{id,role,content,createdAt,conversationId}`. Same UUID+same payload replays retained response; no duplicate AI calls. Missing provider → 503, upstream failure → 502, budget exhausted → 429. AI is never mocked in normal runtime.
- GET `/conversations?q=` → `{id,title,createdAt}[]`; POST `{title}` → 201; GET `/conversations/{id}/messages` → `{id,role,content,createdAt}[]`; POST messages takes assistant input; DELETE conversation → 204.
- GET `/courses` → `{id,title,level,description,contentStatus,lessonCount,completedCount}[]`.
- GET `/courses/{id}/lessons` → `{id,courseId,title,objective,position,kind,contentStatus,status,bestScore}[]`. status `NOT_STARTED|IN_PROGRESS|PRACTICED|PASSED`; kind `LESSON|CHECKPOINT|APPLICATION`; unreviewed content visibly labeled `DRAFT`.
- GET `/lessons/{id}` → above + `{body,questions:[{id,prompt,options:[string],type:MULTIPLE_CHOICE|WRITING}],draftAnswers:object}`. Correct answers are server-only.
- PUT `/lessons/{id}/draft` `{answers:{questionId:string}}` → lesson; no score/progress credit for opening/saving.
- POST `/lessons/{id}/attempts` `{requestId,answers:{questionId:string},assisted:boolean}` → `{id,lessonId,score,passed,assisted,feedback:[{questionId,correct,expected,explanation}],createdAt}`. Server grading; writing gets feedback/reference, never automatic mastery. Repeat requestId must match payload.
- POST `/study-sessions` `{requestId,plannedMinutes:5|20|30}` → `{id,plannedMinutes,activeSeconds,status,version}`. PUT `/study-sessions/{id}` `{activeSeconds,version,completed}` → session. Seconds are cumulative, bounded by wall time and 8h; frontend increments only while visible and active. GET `/study-sessions/current` → session or 204.
- GET `/dashboard` → `{notebookCount,dueCount,reviewCount,retentionRate,dailyMinutes,weeklyActivity:[{date,reviews}],aiUsage:{requests,inputTokens,outputTokens,estimatedCost},completedLessons,activeMinutesToday,weeklyLearning:[{date,activeMinutes,attempts}],nextLesson}`. No listening/speaking score when unassessed.
- GET `/data-export` → versioned backup with profile, learningItems, reviewCards, reviews, conversations, messages, lessonDrafts, lessonAttempts, studySessions and usage (no passwords/keys). POST `/data-import` accepts exported backup to restore into an empty personal workspace, transactionally, using current signed-in owner; 409 if workspace nonempty. Budgets are not reset by erase/import.
- DELETE `/personal-data` → 204: clear learning, chat and study data, keep account and budget counters.

Runtime configuration comes from environment. Default private mode uses PostgreSQL; dev profile uses persistent H2. AI provider is a configurable Chat Completions compatible endpoint, server credentials only. Course content is versioned JSON imported into DB, never arrays embedded in React. Content review and live AI qualification are separate acceptance tasks.

## Image Tutoring

- GET `/assistant-capabilities` (authenticated) returns `{imageEnabled,imageModelConfigured,maxImages,maxImageBytes,maxTotalImageBytes,maxImagePixels,imageTasks:[string]}`. Availability requires configured vision provider/model and explicit `AI_VISION_ENABLED=true`; server is the source of upload limits.
- POST `/assistant-requests` additionally accepts `multipart/form-data`: `metadata` is an `application/json` part `{content?:string,context?:string,requestId:UUID,conversationId?:UUID,task:ANSWER_ONLY|DETAILED|HINT|TRANSLATE|TRANSCRIBE|PRACTICE,questionNumbers?:string,learnerAnswer?:string}`; `images` repeats binary JPEG/PNG parts in reading order. Content may be empty when images are supplied. Initial limits: 3 images, 5 MiB each, 12 MiB total, 16 million decoded pixels each. No arbitrary image URLs, SVG, PDF, GIF or client-only MIME trust.
- Response retains `{id,role,content,createdAt,conversationId}`. For image requests, `content` is serialized JSON with `kind:"IMAGE_ANALYSIS"`, `task`, `summary`, `extractedText`, `warnings:[string]`, `questions:[{number,prompt,status:ANSWERED|NEEDS_CLEARER_IMAGE|NEEDS_CONTEXT|NO_ANSWER_REQUESTED,answer:string|null,explanation,translation,options:[{label,text,verdict:CORRECT|INCORRECT|UNDETERMINED,explanation}],knowledge:[string],tips:[string]}]`, `practice:[{prompt,answer,explanation}]`. No answer in HINT/TRANSCRIBE/TRANSLATE, practice only for PRACTICE. Ambiguous/missing question text or choices must produce warnings and non-ANSWERED status; model judgments are not certified answer keys.
- Same request ID with same normalized image pixels+metadata replays retained result; changed image/task/payload returns 409, concurrent duplicate does not call provider again. JPEG EXIF rotation/reflection is applied before metadata is removed; fingerprint hashes oriented dimensions+ARGB pixels, not palette/encoding bytes. Raw images/base64 are never stored in DB, backups, logs or browser persistent storage. They are sent only to the configured provider. Retained conversation contains extracted text and result, so follow-up can use a compact text reference but original pictures must be reattached when needed. Failed upstream requests remain charged at reservation and cannot reuse their UUID; UI offers an explicit new request with a cost warning, never automatically creates a new paid request on network retry.
- Bad/corrupt image → 400, unsupported media → 415, size/pixel/request limit → 413, disabled/unconfigured vision → 503, provider/model failure or malformed structured output → 502, budget limit → 429. Authentication, CSRF, ownership and privacy behavior are identical to text requests. Detailed image output has a separate configured token cap; token/cost reservations include a configurable per-image allowance, not a claim to precisely predict every provider's image billing.

## B1 Exam

- GET `/b1-exam` → `{title,description,sections:[{id,title,kind,description,groups:[{id,title,instructions,passage?,questions:[{id,number,prompt,type,options?,image?,sourcePage?,unavailable?}]}]}]}`. Content is transcribed from the supplied scanned PDF; missing or illegible source material is marked unavailable. The response contains no answer keys.
- GET `/b1-exam/answers/{questionId}` → `{answer,explanation,translation,kind}` for available non-listening questions; 404 for missing questions, unavailable answers and all listening questions. Writing and speaking responses are examples, not unique certified answers.
- GET `/b1-exam/images/{name}` returns an authenticated cropped source image for a question; only approved image filenames are accepted. Some scans retain handwritten marks that are not verified answer keys. No listening audio is provided.
- GET `/b1-exam/draft` → `{responses:{questionId:string},version}` returns the signed-in learner’s draft; missing draft returns an empty map and version 0. PUT `/b1-exam/draft` takes the same shape, validates question IDs and option values, and uses optimistic locking: a stale conflicting version returns 409; replay of the previous request with the same payload returns the saved result. Drafts are included in data export/import and erased with personal data.
- The exam has no time limit. While the page is visible it periodically checks the authenticated session; after losing connectivity or a conflicting edit, unsaved changes must be retried or reconciled before leaving the page.
